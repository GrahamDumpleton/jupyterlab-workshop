jupyterlab-workshop

Guided, interactive workshops inside JupyterLab.

Workshop instructions are shown in a JupyterLab side panel and contain clickable actions that drive the live session: terminals, the file browser, the editor, notebooks, kernels and layout. Workshops can check what the learner has done, ask questions, and hold pages until requirements are met. A workshop is a directory with a workshop.yaml manifest and Markdown pages, and it runs wherever JupyterLab runs, including entirely in the browser with JupyterLite.

The concept comes from the Educates Training Platform, re-imagined so that a single workshop runs wherever JupyterLab runs, without Kubernetes or containers.
